# Task 2 – Sentiment Analysis with NLP

## Objective
Perform sentiment analysis on customer reviews using TF-IDF vectorization and Logistic Regression.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Steps
1. Collected sample customer reviews
2. Preprocessed text data
3. Converted text into numerical features using TF-IDF
4. Trained Logistic Regression model
5. Evaluated model using accuracy and classification report

## Output
The model successfully classifies reviews into positive and negative sentiments.
